Privacy Policy

Last updated: September 15, 2026

donko is a personal AI assistant that I run on my own private server. I am its only user. It is not offered to anyone else, so no one else's data is ever involved.

The only data donko accesses is my own Google Calendar, through two scopes. calendar.app.created lets it write only to calendars it creates itself — it cannot modify my existing calendars. calendar.readonly lets it read my calendars.

donko does not collect, store, sell, or share this data with any third party. The OAuth token it uses is kept on my own server and nowhere else. Calendar data is used only to answer my own requests and is not sent anywhere beyond the Google APIs it was retrieved from.

Access can be revoked at any time at myaccount.google.com under Security → third-party access.
