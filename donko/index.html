donko

donko is a personal AI assistant I built for myself. It runs on my own private server and I am its only user — there are no other users, no sign-ups, and no public interface.

The only outside data it touches is my own Google Calendar. It uses two scopes: calendar.app.created, which lets it write only to calendars it creates itself and not to any of my existing ones, and calendar.readonly, which lets it read my calendars. It does not collect, store, sell, or share data with any third party.
